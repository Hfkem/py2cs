# 迷宮程式為Gemini生成，已將程式閱讀並標上註釋 
迷宮程[對話連結](https://gemini.google.com/share/8f9271d495a3)此對話為程式功能概略及歷程  
## maze.py  
原版 maze.py為一般平面迷宮，使用遞迴演算法　　
## 3Dmaze.py  
3Dmaze.py以平面基礎上增加縱向路徑，讓迷宮立體化  
此版本縱向路徑與平面路徑判斷相同，因此兩層樓中會有一層牆壁夾層  
## 3Dmaze2.py  
增加"機率"避免縱向通道過度產生，去除牆壁夾層，將縱向通道之標籤改良，以層數為基準並將該層數所有路徑給上數字增加可讀性  
例:第一層代號為A，若該層有10個縱向路徑則依產生順序標上(A1~A10)  
## 3Dmaze3.py  
現在縱向路徑不再被限制於單層跳躍，而是在所有樓層間隨機跳躍  
## 3Dmaze4.py  
將單純遞迴算法，結合生成樹算法  
當迷宮開始產生路徑時，迷宮會以50%的機率選擇從上次結束的位置開始或是從儲存的位置隨機抽選。  
所儲存的位置為迷宮挖掘時的所有起點位置
